## About

I'm a Software Engineering student interested in turning algorithms into useful, maintainable software.

- **Computer vision:** image processing, optical measurement, and real-time desktop tools.
- **LLM applications:** information extraction, prompt-driven workflows, and AI agents.
- **Software engineering:** clear architecture, practical interfaces, and end-to-end implementation.
- **Writing:** I document experiments and lessons learned on my [personal blog](https://2jone.top).
